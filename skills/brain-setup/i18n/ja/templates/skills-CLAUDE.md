エージェントが使うスキルのメモと好み、そしてブレイン整理係が入っています。

## 構成

```
スキル/{skill-name}/
  {skill-name}.md または SKILL.md   そのスキルが何をするか
  notes.md                          このスキルでの{Name}さんらしい言葉づかいと好み
  references/                       例や長めの資料
```

## 入っているスキル

| スキル | フォルダー | 何をするか |
|---|---|---|
| ブレイン整理係 | `ブレイン整理係/` | 毎日の自動の整理と、{Name}さんに頼まれたときの総点検 |
| 朝のまとめ | `朝のまとめ/` | その日の短いプラン。頼まれたとき、または仕事の日は毎日 |
| 取り込み | `取り込み/` | ほかのアプリのメモを取り込む。先に{Name}さんが計画を承認 |
| 打ち合わせ準備 | `打ち合わせ準備/` | 電話の前に、ブレインのノートから短いまとめを作る |
| 思考ツール | `思考ツール/` | アイデアに反論する、パターンを見つける、食い違うノートを見つける |
| 連携アプリ | `連携アプリ/` | ブレインがどのアプリを読むか、そのルール |
| No AI Slop | `no-ai-slop/` | 文章チェック：文章を人間らしく直す、またはAIっぽいパターンを指摘する（Peter Yang作、MITライセンス、編集しない） |

## ルール

- スキル1つにつきフォルダー1つ。英字の名前はケバブケース（小文字とハイフン）にします。
- 新しいスキルを追加したら、上の表に一行追加します。
- ほかの人が作った `SKILL.md` は絶対に編集しません。スキルを自分用に変えたいときは、そのフォルダーに `メモ.md` を追加します。
- `ブレイン整理係/毎日の整理.md` は予定タスクが読むファイルです。毎日の実行内容を変えたいときだけ変更し、シンプルに保ってください：リンクなし、コールアウトなし。
