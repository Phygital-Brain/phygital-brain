# Getting help

| You want to | Go to |
|---|---|
| Learn how to set it up | [Getting started](docs/getting-started.md) |
| Fix a problem yourself | [If something goes wrong](docs/getting-started.md#if-something-goes-wrong) |
| Find a quick answer | [FAQ](docs/faq.md) |
| Report a bug | [Something doesn't work](https://github.com/Phygital-Brain/phygital-brain/issues/new?template=bug_report.yml) |
| Ask a question | [Question](https://github.com/Phygital-Brain/phygital-brain/issues/new?template=question.yml) |
| Share an idea | [Idea or feature](https://github.com/Phygital-Brain/phygital-brain/issues/new?template=feature_request.yml) |
| Report a security problem, privately | [Private report](https://github.com/Phygital-Brain/phygital-brain/security/advisories/new) ([SECURITY.md](SECURITY.md)) |

Issues are public. Leave out passwords, keys, tokens and private data. This is a project run in spare time, so answers can take a few days.
