# मराठी शब्दसूची (mr)

## संबोधन

- **ॲप आणि एजंट व्यक्तीशी बोलताना: "तुम्ही"**, आदरार्थी आज्ञार्थासह (करा, पाहा, निवडा). Google, WhatsApp, PhonePe सारखी लोकप्रिय ॲप्स मराठीत असेच बोलतात. संपूर्ण संचात हेच: फॉर्म, मेसेज आणि नियमांच्या फाइली (एजंटसाठीच्या सूचनाही "वाचा, लिहा" अशाच).
- **व्यक्ती आपल्या एजंटशी बोलते तेव्हा: "तू" आज्ञार्थ** (कर, दे, सांग). लोक सहाय्यकाशी खरोखर असेच बोलतात: "माझ्या ब्रेनची तपासणी कर". कमांडची वाक्ये (ट्रिगर) याच रूपात, आणि नंतर इंग्रजी वाक्य.
- **लिंग:** मराठीत क्रियापदे लिंग दाखवतात. {Name} साठी कोणतेही सर्वनाम नाही: इंग्रजीत जिथे "they" आहे तिथे पुन्हा {Name} लिहिले आहे, आणि आदरार्थी अनेकवचन वापरले आहे ("{Name} सांगतात", "{Name} यांनी ठरवले", "{Name} यांचे नियम"), जे पुरुष आणि स्त्री दोघांसाठी सारखेच चालते. "तुम्ही करता", "तुम्ही केले" ही रूपेही लिंगनिरपेक्ष आहेत. फॉर्ममधील पर्याय आणि एजंटच्या स्वतःच्या ओळी लिंग न दाखवता लिहिल्या आहेत ("आत्ता हे काम कोणासाठी आहे?", "जुन्या नोट्स आत्ता आणू का?"), "करतो/करते" असे तिरके पर्याय कुठेही नाहीत. टीमच्या तक्त्यात भूमिका "प्रमुख" (मालक/मालकीण टाळले), आणि मजकुरात "आधी {Name} यांना विचारा".
- **लेखन:** प्रमाण लिखित मराठी (केले, हवे, उत्तरे), कारण ॲप्स आणि वर्तमानपत्रे असेच लिहितात. फक्त व्यक्ती बोलते ती वाक्ये बोलीच्या जवळ ("ब्रेन कीपरने काय केलं?"). वाक्याच्या शेवटी पूर्णविराम (.), दंड (।) नाही. आकडे अंकांत.
- **शब्द:** रोजचे मराठी, आणि लोक ॲप्समध्ये खरोखर वापरतात ते इंग्रजी शब्द: फाइल, फोल्डर, नोट, लिंक, क्लायंट, टूल, ॲप, बॅकअप, चॅट, ईमेल, सेटअप. मराठीत नुक्ता वापरत नाहीत (फाइल, फोल्डर, फोन). हिंदी शब्द टाळले: निर्णय (फैसला नाही), अडचणी (परेशानियाँ नाही), हिशोब, आढावा, तपासणी.

## मुख्य फोल्डर

| इंग्रजी | मराठी |
|---|---|
| About | ओळख |
| Daily | रोजनिशी |
| Projects | प्रकल्प |
| Relationships | संपर्क |
| Memory | स्मृती |
| Library | लायब्ररी |
| Skills | स्किल्स |

- **ओळख**, "माझ्याबद्दल" नाही: एकच शब्द, आणि फोल्डरमध्ये फक्त व्यक्तीच नाही तर ध्येये, व्यवसाय, ब्रँडही आहेत.
- **रोजनिशी**: रोजची डायरी, अगदी घरगुती शब्द.
- **प्रकल्प**: शाळेपासून सगळ्यांना माहीत असलेला मराठी शब्द.
- **संपर्क**, "नाती" नाही: "नाती" कुटुंबासारखे वाटते; इथे क्लायंट, सहयोगी, टीम आणि भागीदार आहेत.
- **स्मृती**: "आठवणी" जुन्या गोड आठवणींसारखे वाटते, आणि "मेमरी" फोनच्या स्टोरेजसारखे.
- **लायब्ररी**: लोक असेच म्हणतात. "ग्रंथालय" पुस्तकांच्या इमारतीसारखे वाटते.
- **स्किल्स**: एजंट ॲप्स हाच शब्द वापरतात. "कौशल्ये" माणसाच्या कौशल्यांसारखे वाटते.

- **archive = जुने**: "Memory/जुने/निर्णय" सहज वाचता येते. "संग्रहण" अनेकांना कळत नाही. मजकुरात "जुन्यांमध्ये हलवा".
- **cv = बायोडेटा**: महाराष्ट्रात CV ला सगळे हेच म्हणतात.
- **tasks = करायची-कामे**: फक्त "कामे" लिहिले तर "काम" (नोकरी, work) शी गोंधळ होतो.
- **queue = बाकी-मुद्दे**: "रांग" तांत्रिक वाटते. मजकुरात ही फाइल "बाकी मुद्द्यांची यादी".
- **Brain Keeper ची `daily.md` = रोजची-आवराआवर**, म्हणजे `Daily` फोल्डरशी (रोजनिशी) गोंधळ होत नाही.
- **tools = साधने**: "विचार-साधने" मध्येही तोच शब्द, एका कल्पनेला एकच शब्द.
- **_Leads = _लीड्स**: व्यवसाय करणारे लोक हाच शब्द वापरतात.

स्थानिक नावे, सगळीकडे सारखी: Ana Costa → सई देशपांडे, Marta → मानसी, João → ओंकार, Lia → लीना. फॉर्ममधील ठिकाण "Lisbon, Portugal" ऐवजी "पुणे, महाराष्ट्र", उदाहरण वेबसाइट "https://tumchi-website.in". सोशल मीडियाच्या उदाहरणात TikTok (भारतात बंद) ऐवजी YouTube.

## कंसातील placeholders

खरे placeholders (`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` वगैरे) जसेच्या तसे राहतात. ज्या कंसात भरायची सूचना किंवा एजंट नोटमध्ये लिहील असा नमुना मजकूर आहे (उदाहरणार्थ `{एक वाक्य: या फाइलमध्ये काय आहे.}`), तो मराठीत आहे, म्हणजे नोटमधील मजकूर मराठीत येतो.
