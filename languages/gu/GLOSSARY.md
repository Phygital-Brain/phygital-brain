# ગુજરાતી (gu) શબ્દસૂચિ

## સંબોધન

આદરવાળું "તમે", જેમ મોટા ભાગની ગુજરાતી કન્ઝ્યુમર એપ્સ (WhatsApp, Google, Paytm, PhonePe) વાપરે છે. આખા સેટમાં એક જ રીત: ફોર્મ, મેસેજ અને નિયમોની ફાઇલો (એજન્ટ માટેની સૂચનાઓ પણ "તમે"ના રૂપમાં: વાંચો, લખો, પૂછો). વ્યક્તિ પોતાના એજન્ટને જે વાક્યો કહે છે (ટ્રિગર) તે પણ "કરો, આપો, કરાવો" જેવાં રૂપમાં છે, કારણ કે લોકો આસિસ્ટન્ટ સાથે એમ જ વાત કરે છે: "મારા બ્રેનનું ચેક-અપ કરો". દરેક ટ્રિગર પછી અંગ્રેજી વાક્ય પણ છે, જેથી બંને ચાલે.

ભાષા રોજની બોલચાલની છે, હિન્દીના શબ્દો નહીં. લોકો એપ્સમાં જે અંગ્રેજી શબ્દો ખરેખર બોલે છે તે ગુજરાતી લિપિમાં રાખ્યા છે: ફાઇલ, ફોલ્ડર, લિંક, પ્રોજેક્ટ, ક્લાયન્ટ, ટૂલ્સ, એપ્સ, બેકઅપ, રિપોર્ટ, ચેટ, ઈમેલ, સેટઅપ. જ્યાં સહેલો ગુજરાતી શબ્દ છે ત્યાં તે જ: નોંધ, ધ્યેય, નિર્ણય, હિસાબ, યાદી.

**{Name} માટે લિંગ નહીં.** ગુજરાતીમાં ભૂતકાળનાં ક્રિયાપદ અને કેટલાંક વિશેષણ લિંગ બતાવે છે ("ગયા/ગયાં", "સારો/સારી"). તેથી {Name} કર્તા હોય ત્યાં વર્તમાન કે ભવિષ્યકાળ વપરાય છે ("{Name} કહે છે", "{Name} નક્કી કરશે"), અથવા "{Name}એ" સાથેનું રૂપ, જેમાં ક્રિયાપદ કર્મ સાથે જાય છે ("{Name}એ થોભાવ્યું"). "તેઓ" કે "તે" લિંગ વગરના છે, પણ બને ત્યાં {Name} ફરીથી લખ્યું છે. ફોર્મના વિકલ્પો પણ એવા લખ્યા છે કે કોઈ પણ વ્યક્તિને લાગુ પડે.

વાક્યના અંતે પૂર્ણવિરામ (.), સંખ્યાઓ આંકડામાં (1, 2, 3).

## ફોલ્ડર (સૌથી ઉપરનું સ્તર)

ગુજરાતીમાં મોટા-નાના અક્ષર નથી, તેથી ઉપરનાં ફોલ્ડર ફક્ત શબ્દ છે. નામમાં એકથી વધુ શબ્દ હોય તો હાઇફનથી જોડાય છે.

| અંગ્રેજી | ગુજરાતી |
|---|---|
| About | પરિચય |
| Daily | રોજનીશી |
| Projects | પ્રોજેક્ટ |
| Relationships | સંપર્કો |
| Memory | સ્મૃતિ |
| Library | લાઇબ્રેરી |
| Skills | સ્કિલ્સ |

- **પરિચય**: એક શબ્દ, અને ફોલ્ડરમાં ફક્ત વ્યક્તિ નહીં, ધ્યેય, બિઝનેસ અને બ્રાન્ડ પણ છે. "મારા વિશે" કરતાં વધુ પૂરું.
- **રોજનીશી**: ગુજરાતીમાં ડાયરી માટેનો જાણીતો, ઘરગથ્થુ શબ્દ. દરેક દિવસની એક નોંધ, એ જ આ ફોલ્ડર છે.
- **સંપર્કો**, "સંબંધો" નહીં: "સંબંધો" કુટુંબ અને સગપણ જેવું લાગે છે. આ ફોલ્ડરમાં ક્લાયન્ટ, સહયોગીઓ, ટીમ અને પાર્ટનર છે.
- **સ્મૃતિ**: ટૂંકો, સ્પષ્ટ શબ્દ. "યાદો" લાગણીવાળી યાદો જેવું લાગે, અને "મેમરી" ફોનના સ્ટોરેજ જેવું.
- **લાઇબ્રેરી**: "પુસ્તકાલય" ફક્ત પુસ્તકો માટે લાગે છે, અહીં પ્રોમ્પ્ટ અને ટેમ્પ્લેટ પણ છે.
- **સ્કિલ્સ**: એજન્ટ એપ્સ આ જ શબ્દ વાપરે છે. "આવડત" અહીં અજાણ્યું લાગે.

- **customers = ગ્રાહકો**, "ક્લાયન્ટ" નહીં: નહીં તો પરિચયમાં `ક્લાયન્ટ.md` અને સંપર્કોમાં `ક્લાયન્ટ` ફોલ્ડર બંને હોત, જે સહેલાઈથી ગૂંચવાય.
- **cv = બાયોડેટા**: ગુજરાતમાં નોકરી માટે લોકો આ જ શબ્દ બોલે છે.
- **finances = હિસાબ**: પૈસાનો હિસાબ રાખવા માટેનો રોજનો શબ્દ.
- **tasks = કામની-યાદી**: ફક્ત "કામ" લખીએ તો "work" સાથે ગૂંચવાય.
- **queue = બાકી-મુદ્દા**: "કતાર" ટેકનિકલ લાગે. લખાણમાં આ ફાઇલને "બાકી મુદ્દાની યાદી" કે ટૂંકમાં "યાદી" કહી છે.
- **ગોઠવણ સહાયકની `daily.md` = રોજની-ગોઠવણ**, જેથી તે `Daily` ફોલ્ડર (રોજનીશી) સાથે ન ગૂંચવાય.
- **ideas = આઇડિયા**, "વિચારો" નહીં, જેથી `thinking` (વિચાર-સાધનો) સાથે ન ગૂંચવાય.
- **assets = મીડિયા**: ફોલ્ડરમાં ચિત્રો અને મીડિયા છે.
- **_Leads = _લીડ્સ**: કામમાં આ શબ્દ જાણીતો છે. લખાણમાં સમજાવ્યું છે કે લીડ એટલે હજી ક્લાયન્ટ ન બનેલી વ્યક્તિ.

ઉદાહરણનાં નામ ગુજરાતી કર્યાં છે, અને બધે એક જ રીતે વપરાય છે: Ana Costa → અંજલિ મહેતા (`[[અંજલિ]]`), Marta → કિંજલ, João → ધવલ, Lia → રીના. ફોર્મમાં સ્થળ "Lisbon, Portugal"ને બદલે "અમદાવાદ, ભારત", અને ઉદાહરણ વેબસાઇટ "https://tamarisite.com". સોશિયલ મીડિયાના ઉદાહરણમાં TikTok (ભારતમાં બંધ છે)ને બદલે YouTube.

## કૌંસમાંના પ્લેસહોલ્ડર

સાચા પ્લેસહોલ્ડર (`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` વગેરે) જેમ છે તેમ જ રહે છે. ગુજરાતીમાં સંબંધ બતાવતો પ્રત્યય સીધો પ્લેસહોલ્ડર પછી જોડાય છે: `{Name}ના`, `{Name}ને`, `{Language}માં`. જે કૌંસમાં ભરવાની સૂચના કે ઉદાહરણ લખાણ છે, જે એજન્ટ નોંધમાં લખે છે (જેમ કે `{એક વાક્ય: આ ફાઇલમાં શું છે.}`), તેનો અનુવાદ કર્યો છે, જેથી નોંધમાં લખાણ ગુજરાતીમાં આવે.
