# Ordliste norsk bokmål (nb)

## Tiltaleform

Uformell, «du», slik nesten alle norske forbrukerapper skriver (banker, Vipps, strømmetjenester). «De» er gammeldags og brukes nesten aldri. Likt i hele settet: i skjemaene, i meldingene og i regelfilene (også instruksene til agenten er skrevet med «du»). {Name} får aldri et pronomen: der engelsk sier «they», står {Name} på nytt, eller setningen er skrevet om, så ingen blir feil kjønnet. Roller som «Owner» er skrevet uten kjønn (i team-tabellen «Ansvarlig», i teksten «Spør {Name} først»).

Skrevet på vanlig, moderne bokmål (a-endinger er ikke brukt: «filen», «boken»), ikke dansk eller svensk.

## Mapper (øverste nivå)

| Engelsk | Norsk |
|---|---|
| About | Profil |
| Daily | Dagbok |
| Projects | Prosjekter |
| Relationships | Kontakter |
| Memory | Minne |
| Library | Bibliotek |
| Skills | Ferdigheter |

- **Profil** i stedet for «Om meg»: ett ord, og mappen har mer enn bare personen (mål, bedrift, merkevare).
- **Dagbok** i stedet for «Daglig»: det er det mappen er, ett notat per dag.
- **Kontakter** i stedet for «Relasjoner»: «relasjoner» høres stivt ut, og «forhold» høres ut som kjærlighetsliv.
- **Ferdigheter**: det vanlige norske ordet for skills. Folk forstår det uten forklaring, mens «skills» blir et fremmedord.

## Eksempler

Navnene (Ana, Marta, João, Lia) er de samme som på engelsk. Stedet i skjemaet er «Oslo, Norge» i stedet for «Lisbon, Portugal», og eksempelnettsiden er «https://dittnettsted.no».

## Plassholdere i krøllparenteser

Ekte plassholdere (`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` og så videre) står nøyaktig som de er. Parenteser med en utfyllingsinstruks eller en eksempeltekst som agenten skriver inn i notatet (for eksempel `{Én setning: hva denne filen inneholder.}`), er oversatt, så teksten i notatet blir norsk.

## Anførselstegn

Sitater og utløsere står i «sånne», slik det er vanlig på norsk. Et sitat inne i et sitat står i ‘enkle’.
