Нотатки й уподобання для навичок, якими користується агент, а також Доглядач мозку.

## Структура

```
Skills/{skill-name}/
  {skill-name}.md або SKILL.md   що робить навичка
  notes.md                       як {Name} хоче, щоб працювала ця навичка
  references/                    приклади й довші матеріали
```

## Встановлено

| Навичка | Папка | Що робить |
|---|---|---|
| Доглядач мозку | `brain-keeper/` | Щоденне прибирання саме по собі і перевірка, коли {Name} просить |
| Ранковий огляд | `morning-brief/` | Короткий план на день, на прохання або кожного робочого дня |
| Імпорт | `import/` | Переносить нотатки з інших застосунків за планом, який {Name} спершу схвалює |
| Підготовка до зустрічі | `meeting-prep/` | Коротка довідка перед дзвінком із нотаток мозку |
| Інструменти мислення | `thinking/` | Покритикувати ідею, знайти закономірності, знайти нотатки, які суперечать одна одній |
| Підключені застосунки | `connected-apps/` | З яких застосунків мозок бере інформацію і які для них правила |
| No AI Slop | `no-ai-slop/` | Перевірка тексту: редагує текст, щоб він звучав по-людськи, або позначає шаблони ШІ (автор Peter Yang, ліцензія MIT, ніколи не редагується) |

## Правила

- Одна папка на навичку, назва в kebab-case (малими літерами через дефіс).
- Коли додається нова навичка, додай рядок у таблицю вище.
- `SKILL.md`, отриманий від когось іншого, ніколи не редагується. Щоб підлаштувати навичку, додай `notes.md` у її папку.
- `brain-keeper/daily.md` читає завдання за розкладом. Змінюй його лише для того, щоб змінити щоденний запуск, і тримай простим: без посилань, без блоків-виносок.
