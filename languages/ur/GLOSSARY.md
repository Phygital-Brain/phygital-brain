# اردو فرہنگ (ur)

جدید، روزمرہ کی اردو، جیسی پاکستان کی مشہور ایپس لکھتی ہیں۔ دائیں سے بائیں لکھی جاتی ہے (`"dir": "rtl"`)۔

## مخاطب کا انداز

- **ایپ اور ایجنٹ سے شخص تک: "آپ"**، احترام والے حکم کے ساتھ (کریں، دیکھیں، چنیں)۔ پاکستان کی زیادہ تر ایپس (بینک، JazzCash، Easypaisa، Daraz) یہی لکھتی ہیں۔ پورے سیٹ میں ایک جیسا: فارمز، میسجز، اور اصولوں کی فائلیں (ایجنٹ کے لیے ہدایات بھی "آپ" والی)۔
- **شخص اپنے ایجنٹ سے جو کہتا ہے: "تم" والا حکم** (کرو، دو، بتاؤ)۔ لوگ اسسٹنٹ سے ایسے ہی بات کرتے ہیں: "میرے برین کا چیک اپ کرو"۔ ٹرگر جملے اسی شکل میں ہیں، اور ان کے بعد انگریزی والا جملہ۔
- **جنس:** اردو کے فعل جنس بتاتے ہیں ("کرتے ہیں" اور "کرتی ہیں")۔ {Name} کے لیے کوئی ضمیر یا جنس والا فعل نہیں: جہاں ممکن ہو، دوبارہ {Name} لکھا ہے، یا جملہ ایسے بنایا ہے کہ فعل کسی اور چیز سے ملے ("جب {Name} کہیں"، "{Name} کی ہاں"، "فیصلہ صرف {Name} کے ہاتھ میں ہے")۔ فارمز میں بھی سوال ایسے ہیں کہ ہر کسی کے لیے ٹھیک ہوں ("آپ کا کام کیا ہے؟"، "آپ کے کام کے دن کون سے ہیں؟")۔ ٹیم کی ٹیبل میں "Owner" کی جگہ "ایڈمن"، اور متن میں "پہلے {Name} سے پوچھیں"۔
- انگریزی کے وہ عام الفاظ جو لوگ واقعی بولتے ہیں: فائل، فولڈر، نوٹ، لنک، پروجیکٹ، کلائنٹ، ٹول، ایپ، بیک اپ، رپورٹ، چیٹ، ای میل، سیٹ اپ، اسٹیٹس، ٹیگ۔ جہاں عام اردو لفظ موجود ہو وہاں بھاری عربی فارسی الفاظ نہیں۔
- اعداد مغربی (0 سے 9)، جیسے زیادہ تر ایپس میں، تاکہ اصولوں کے نمبر، وقت اور تاریخیں انفو بلاکس سے میل کھائیں۔ جملے "۔" پر ختم ہوتے ہیں، سوال "؟" پر، اور کاما "،" ہے۔

## فولڈر (سب سے اوپر والے)

| انگریزی | اردو |
|---|---|
| About | تعارف |
| Daily | روزنامچہ |
| Projects | پروجیکٹس |
| Relationships | رابطے |
| Memory | یادداشت |
| Library | لائبریری |
| Skills | اسکلز |

- **تعارف**: ایک لفظ، اور ایپس میں "About" کے لیے یہی لکھا جاتا ہے۔ اس فولڈر میں صرف شخص نہیں، اہداف، کاروبار اور برانڈ بھی ہیں۔
- **روزنامچہ**: روز کی ڈائری کا عام اردو لفظ۔ "روزانہ" صفت ہے، اور برین کیپر کی `daily.md` سے الجھ سکتا تھا۔
- **رابطے**، "تعلقات" نہیں: "تعلقات" ذاتی رشتوں جیسا لگتا ہے، جبکہ یہاں کلائنٹس، ساتھی، ٹیم اور پارٹنرز ہیں۔
- **یادداشت**، "یادیں" نہیں ("یادیں" پرانی خوشگوار باتوں کے لیے بولا جاتا ہے)۔
- **اسکلز** انگریزی سے، کیونکہ ایجنٹ ایپس یہی لفظ استعمال کرتی ہیں۔ "مہارتیں" یہاں اجنبی لگتا ہے۔

اردو میں بڑے چھوٹے حروف نہیں ہوتے، اس لیے اوپر والے فولڈر بس لفظ ہیں۔ کئی الفاظ والے نام ہائفن سے جڑے ہیں۔ ناموں میں اعراب (زیر، زبر، پیش، تشدید) نہیں، تاکہ سرچ اور سنک ہر ڈیوائس پر ایک جیسے چلیں۔

- **customers = گاہک**، "کلائنٹس" نہیں: ورنہ تعارف میں `کلائنٹس.md` اور رابطوں میں `کلائنٹس` فولڈر دونوں ہوتے، اور یہ آسانی سے الجھ جاتے۔
- **finances = حساب-کتاب**: پیسوں کا ریکارڈ رکھنے کا روزمرہ لفظ۔
- **tasks = کرنے-کے-کام**: صرف "کام" لکھتے تو یہ ہر طرح کے کام (نوکری، پروجیکٹ) سے الجھ جاتا۔
- **queue = زیر-التوا**: دفتروں میں رکی ہوئی چیزوں کے لیے یہی لفظ بولا جاتا ہے۔ متن میں اسے "زیر التوا فہرست" کہا گیا ہے۔
- **_Leads = _ممکنہ-کلائنٹس**: "لیڈز" ہر کوئی نہیں سمجھتا۔
- **daily (برین کیپر کی روزانہ رن والی فائل) = روزانہ-صفائی**، تاکہ `Daily` فولڈر (روزنامچہ) سے الگ رہے۔
- **biography = میری-کہانی**، تاکہ `سی-وی` سے الگ رہے۔
- **assets = میڈیا**: اس فولڈر میں تصویریں اور میڈیا ہوتا ہے۔

## مثالیں

مثالوں کے نام مقامی ہیں، اور ہر جگہ ایک جیسے: Ana Costa کی جگہ عائشہ خان (ayesha.draws، ayeshakhan، ayeshasketchbook)، Marta کی جگہ مریم، João کی جگہ علی، Lia کی جگہ ثنا، اور Lisbon, Portugal کی جگہ لاہور، پاکستان۔ ویب سائٹ کی مثال https://yoursite.com ہی رہتی ہے۔

## کرلی بریکٹس والے placeholders

اصل placeholders (`{Name}`، `{Language}`، `{person or company}`، `{weekday in English}` وغیرہ) بالکل ویسے ہی رہتے ہیں۔ جن بریکٹس میں بھرنے کی ہدایت یا مثال کا متن ہے جو ایجنٹ نوٹ میں لکھتا ہے (جیسے `{ایک جملہ: اس فائل میں کیا ہے۔}`)، ان کا ترجمہ کیا گیا ہے، تاکہ نوٹ میں متن اردو میں ہو۔

## ٹرگر جملے

پہلے اردو جملہ، پھر انگریزی والا، تاکہ دونوں چلیں: "میرے برین کا چیک اپ کرو" ("check up my brain")۔
