# อภิธานศัพท์ภาษาไทย (th)

## การเรียกผู้ใช้

สุภาพแต่เป็นกันเอง เรียกว่า "คุณ" แบบที่แอปไทยส่วนใหญ่ใช้ (เช่น LINE, Grab, แอปธนาคาร) ใช้แบบเดียวกันทั้งชุด: ในฟอร์ม ข้อความ และไฟล์กฎ (คำสั่งถึงเอเจนต์ก็เรียกเอเจนต์ว่า "คุณ")

- ไม่ใช้คำลงท้าย ครับ/ค่ะ เพราะบอกเพศของผู้พูด ถ้าประโยคต้องการความนุ่มนวล ใช้ "หน่อย" "ได้เลย" "นะ" หรือเรียบเรียงใหม่แทน
- ไม่มีสรรพนามสำหรับ {Name}: ตรงไหนที่ภาษาอังกฤษใช้ "they" จะใส่ {Name} ซ้ำ หรือเรียบเรียงใหม่ เพื่อไม่ให้ระบุเพศผิด คนอื่นในตัวอย่าง (ลูกค้า ผู้ติดต่อ) เรียกว่า "คนนั้น"
- ประโยคที่คนพูดกับเอเจนต์ (คำสั่งเริ่มงาน) เป็นภาษาพูด เช่น "ช่วยตรวจเช็กสมองให้หน่อย" ตามด้วยประโยคภาษาอังกฤษเสมอ
- เขียนแบบไทย: ไม่เว้นวรรคระหว่างคำในประโยค เว้นวรรคระหว่างวลีหรือประโยค และเว้นวรรครอบคำภาษาอังกฤษ ตัวเลข และโค้ด ไม่ใช้ขีดยาว (em dash)
- `{Language}` จะถูกแทนด้วยชื่อภาษา ("ไทย") จึงเขียนว่า "ในภาษา{Language}" ให้อ่านได้ว่า "ในภาษาไทย"

## โฟลเดอร์ชั้นบนสุด

| อังกฤษ | ไทย |
|---|---|
| About | โปรไฟล์ |
| Daily | บันทึกรายวัน |
| Projects | โปรเจกต์ |
| Relationships | ผู้ติดต่อ |
| Memory | คลังความรู้ |
| Library | ห้องสมุด |
| Skills | สกิล |

- **โปรไฟล์** แทน "เกี่ยวกับฉัน": คำเดียว และในโฟลเดอร์มีมากกว่าเรื่องของตัวเอง (เป้าหมาย ธุรกิจ แบรนด์)
- **บันทึกรายวัน**: คำที่ใช้กันจริง และโฟลเดอร์นี้คือบันทึกทีละวัน
- **โปรเจกต์**: สะกดตามราชบัณฑิตยสภา และเป็นคำที่คนทำงานพูดกัน
- **ผู้ติดต่อ** แทน "ความสัมพันธ์": "ความสัมพันธ์" ฟังเหมือนเรื่องความรัก ส่วน "ผู้ติดต่อ" คือคำที่มือถือและแอปอีเมลใช้
- **คลังความรู้** แทน "ความทรงจำ": "ความทรงจำ" ฟังซึ้งเกินไป ในโฟลเดอร์นี้คือการตัดสินใจ ข้อมูลค้นคว้า ใบสมัคร และของที่เก็บถาวร
- **ห้องสมุด**: เป็นภาพที่เข้าใจง่าย ที่เก็บของที่หยิบมาใช้ซ้ำได้
- **สกิล** แทน "ทักษะ": แอปเอเจนต์และคนใช้ AI ในไทยเรียก "สกิล" กันทั่วไป "ทักษะ" ฟังเป็นทางการและไม่ตรงความหมายในที่นี้

- ภาษาไทยไม่มีตัวพิมพ์ใหญ่และไม่เว้นวรรคระหว่างคำ ชื่อจึงไม่มีขีดคั่น

## ข้อความแทนที่ในวงเล็บปีกกา

ข้อความแทนที่จริง (`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` และอื่นๆ) คงไว้ตามเดิมทุกตัวอักษร วงเล็บที่เป็นคำอธิบายว่าต้องเขียนอะไร หรือเป็นข้อความตัวอย่างที่เอเจนต์จะเขียนลงในโน้ต (เช่น `{หนึ่งประโยค: ไฟล์นี้เก็บอะไร}`) แปลเป็นไทย เพื่อให้ข้อความในโน้ตเป็นภาษาไทย
