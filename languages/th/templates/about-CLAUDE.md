โฟลเดอร์นี้เก็บข้อมูลหลักเกี่ยวกับ {Name} โน้ตในนี้คือข้อมูลที่ถูกต้องที่สุด งานอื่นทั้งหมดอ้างอิงจากที่นี่

## ไฟล์

| ไฟล์ | เก็บอะไร | แท็กหมวด |
|---|---|---|
| `me.md` | {Name} เป็นใคร ทำงานแบบไหน และอยากให้เอเจนต์ทำงานให้แบบไหน | `identity` |
| `biography.md` | เรื่องราวชีวิตของ {Name} | `identity` |
| `goals.md` | เป้าหมายและเรื่องที่ให้ความสำคัญก่อน | `goals` |
| `business.md` | ธุรกิจ | `business` |
| `services.md` | บริการ สินค้า ข้อเสนอ | `business` |
| `customers.md` | ใครเป็นคนซื้อ และรู้จัก {Name} จากทางไหน | `customers` |
| `pain-points.md` | ปัญหาที่ต้องแก้ | `customers` (หรือ `goals` ถ้า {Name} ไม่ได้ขายอะไร) |
| `brand.md` | สไตล์การพูด น้ำเสียง คำที่ใช้และคำที่เลี่ยง | `brand` |
| `tools.md` | เครื่องมือที่ใช้ และของแต่ละแบบเก็บไว้ที่ไหน | `tools` |
| `cv.md` | ประวัติการทำงาน การศึกษา ผลงานในสื่อ รางวัล | `career` |

## บล็อกข้อมูล (frontmatter)

ทุกไฟล์ในนี้ (ยกเว้นไฟล์นี้) ขึ้นต้นด้วย:

```yaml
---
type: about
status: active
updated: 2026-10-13
tags: [about, identity, working-style]
description: "{Name} เป็นใคร และอยากให้เอเจนต์ทำงานให้แบบไหน"
---
```

- `type`: เป็น `about` เสมอ
- `status`: `active` หรือ `outdated` เมื่อรู้ว่ามีข้อมูลที่เก่าแล้ว
- `updated`: วันที่ข้อมูลเปลี่ยนครั้งล่าสุด ไม่ต้องแก้เมื่อแค่แก้คำผิดหรือปรับสำนวน
- `tags`: `about` ตามด้วยแท็กหมวดของไฟล์จากตารางด้านบน แล้วตามด้วยแท็กหัวข้อที่บอกว่าไฟล์นี้พูดถึงอะไร (ภาษาอังกฤษ ตัวพิมพ์เล็ก คั่นด้วยขีด) เมื่อเพิ่มหรือลบหัวข้อในไฟล์ ให้แก้แท็กหัวข้อตามด้วย
- `description`: หนึ่งประโยคในเครื่องหมายคำพูด บอกว่าไฟล์นี้เก็บอะไร อยู่บรรทัดสุดท้ายเสมอ

## กฎ

- ไฟล์เหล่านี้คือข้อมูลที่ถูกต้องที่สุด อย่าคัดลอกเนื้อหาไปไว้ที่อื่น ให้ลิงก์มาที่นี่แทน
- ใช้รูปแบบ "ข้อมูลล่าสุดอยู่บน หลักฐานอยู่ล่าง" (กฎหลักข้อ 17): ข้อมูลปัจจุบันอยู่ด้านบน หลักฐานพร้อมวันที่อยู่ด้านล่าง
- วันเดือนปีเกิดแบบเต็มของ {Name} เก็บไว้ใน `me.md` ที่เดียว ห้ามคัดลอกหรือยกมาพูดในคำตอบ บอกแค่ปีเกิดได้
- สร้างไฟล์ใหม่ก็ต่อเมื่อมีหัวข้อใหม่ที่ต้องมีไฟล์ของตัวเองจริงๆ ถามก่อนเสมอ (กฎหลักข้อ 9)
- ตอนตรวจเช็ก ให้แจ้งเป้าหมายใน `goals.md` ที่ยังไม่มีโปรเจกต์ไหนทำอยู่
