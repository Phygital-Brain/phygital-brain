Заметки и предпочтения для навыков, которыми пользуется агент, плюс Хранитель мозга.

## Структура

```
Skills/{skill-name}/
  {skill-name}.md или SKILL.md   что делает навык
  notes.md                       голос и предпочтения владельца для этого навыка
  references/                    примеры и материалы подлиннее
```

## Установлено

| Навык | Папка | Что делает |
|---|---|---|
| Хранитель мозга | `brain-keeper/` | Сам наводит порядок каждый день и проводит проверку, когда {Name} просит |
| Утренняя сводка | `morning-brief/` | Короткий план на день, по запросу или каждый рабочий день |
| Импорт | `import/` | Переносит заметки из других приложений по плану, который {Name} сначала одобряет |
| Подготовка к встрече | `meeting-prep/` | Короткая сводка перед созвоном по заметкам мозга |
| Инструменты мышления | `thinking/` | Критикуют идею, находят закономерности и заметки, которые противоречат друг другу |
| Подключенные приложения | `connected-apps/` | Из каких приложений мозг берет информацию и какие для них правила |
| No AI Slop | `no-ai-slop/` | «Проверка текста»: правит тексты, чтобы они звучали по-человечески, или отмечает шаблоны ИИ (автор Peter Yang, лицензия MIT, никогда не редактируется) |

## Правила

- Одна папка на навык, название в стиле kebab-case (строчные буквы через дефис).
- Когда добавляется новый навык, добавь строку в таблицу выше.
- `SKILL.md`, который пришел от кого-то другого, никогда не редактируется. Чтобы настроить навык под себя, добавь `notes.md` в его папку.
- `brain-keeper/daily.md` читает задача по расписанию. Меняй его, только чтобы изменить ежедневный запуск, и держи его простым: без ссылок и без выносок.
