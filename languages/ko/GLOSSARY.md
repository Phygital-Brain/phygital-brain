# 한국어 용어집 (ko)

## 말투

해요체예요. 토스, 카카오톡, 배달 앱처럼 한국의 인기 소비자 앱이 사용자에게 쓰는 부드럽고 공손한 말투예요. 세트 전체에서 똑같이 써요: 양식, 메시지, 규칙 파일(에이전트에게 주는 지시도 해요체, 예: "읽어요", "물어봐요"). 합쇼체("합니다")는 딱딱하고, 반말은 무례하게 들려서 쓰지 않아요.

- 사람은 "{Name}님"이라고 불러요. {Name}에게는 대명사를 쓰지 않아요: 영어에서 "they"라고 하는 곳에는 다시 "{Name}님"이라고 쓰거나, 한국어답게 주어를 빼요. 그래서 성별이 드러나지 않아요. 팀 표의 "Owner"는 "관리자"라고 써요.
- 실행하는 말(사람이 에이전트에게 하는 말)은 "~해 줘" 같은 편한 말로 썼어요. 한국 사람이 AI 비서에게 실제로 말하는 방식이에요. 그 뒤에 영어 문장을 함께 적어요.
- 버튼과 선택지는 앱처럼 짧게: "건너뛰기", "계속", "나중에", "지금 설치하기".
- 문장 부호는 보통의 마침표, 쉼표, 콜론, 괄호. 긴 대시(em dash)는 쓰지 않아요.

## 맨 위 폴더

| 영어 | 한국어 |
|---|---|
| About | 프로필 |
| Daily | 일지 |
| Projects | 프로젝트 |
| Relationships | 인맥 |
| Memory | 기록 |
| Library | 자료실 |
| Skills | 스킬 |

- **프로필**: "나에 대해"보다 짧고, 사람뿐 아니라 목표, 사업, 브랜드까지 담는 폴더라서요.
- **일지**: "일기"는 사적인 감정 기록처럼 들려요. "일지"는 일과 생활을 날마다 적는 기록이에요.
- **인맥**: "관계"는 연애나 가족 이야기처럼 들려요. "인맥"은 함께 일하는 사람들이에요.
- **기록**: 결정, 리서치, 돈, 보관함은 모두 쌓이는 기록이에요. "메모리"는 컴퓨터 부품처럼 들려요.
- **자료실**: 다시 쓰는 자료를 모아 두는 곳이라는 뜻으로 한국 사람에게 익숙한 말이에요.
- **스킬**: 에이전트 앱들이 한국어에서도 이 말을 그대로 써요.

- 한국어에는 대문자와 소문자가 없어요. 두 단어로 된 이름은 하이픈 없이 붙여 써요(아침브리핑, 미팅준비). 한국어 복합 명사는 붙여 쓰는 게 자연스럽고, 하이픈은 어색해 보여요.
- Clients(클라이언트)와 customers(고객)는 다른 말로 둬요. 하나는 사람 폴더이고, 다른 하나는 누가 사는지에 대한 노트예요.
- **finances = 돈관리**: "재무"는 회사 용어처럼 딱딱해요.
- **queue = 확인목록**: "대기열"은 기술 용어처럼 들려요.
- **_Leads = _잠재고객**: "리드"는 마케팅 업계 사람만 알아요.

## 중괄호 자리 표시

진짜 자리 표시(`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` 등)는 그대로 둬요. 에이전트가 노트에 채워 넣을 설명이나 예시가 들어 있는 중괄호(예: `{한 문장으로: 이 파일에 무엇이 있는지.}`)는 번역했어요. 그래야 노트에 들어가는 글이 한국어가 돼요.
