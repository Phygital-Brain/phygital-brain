# Glosarium Bahasa Indonesia (id)

Kata-kata yang dipilih untuk Phygital Brain dalam Bahasa Indonesia, dan alasannya.

## Register

**"kamu"** (informal, ramah), seperti di Gojek, Tokopedia, Shopee, dan Spotify Indonesia. Kepunyaan pakai "-mu" (otakmu, agenmu). Orang yang memakai otak ini berbicara sebagai "aku" (ideku, otakku). Instruksi untuk agen di template juga memakai "kamu" atau kalimat perintah tanpa kata ganti. Tidak pernah "Anda".

## Judul bagian yang dipakai di beberapa file

- README proyek: `## Tentang proyek ini`, `## Status dan langkah berikutnya`, `## Cara jalannya`, `## Letak isinya`
- `tasks.md`: `## Belum selesai`, `## Selesai`
- `_Leads.md`: `## Baru`, `## Tetap dihubungi`
- Halaman Tentang: `## Bukti`
- Antrean: "Terakhir dijalankan", `## Menunggu {Name}`, `## Akan diperbaiki`, `## Folder berikutnya`; kosong = "Tidak ada."
- Laporan: Ringkasan, File yang diubah, Diperbaiki, Masuk antrean, Kesalahan

## Catatan untuk peninjau

- Bagian "Bahasa" di `CLAUDE.md` utama mengikuti versi Inggris: nama folder, nama file, dan `[[tautan]]` ditulis "persis seperti yang tertulis di aturan ini". Kunci dan nilai blok info tetap bahasa Inggris.
- Semua jalur ditulis dalam bahasa Inggris dan diubah oleh skrip build, termasuk `.backups/...` (bagian setelah folder tanggal ikut dipetakan). Nama folder cadangan sendiri (`2026-10-24-1530-impor`) bebas, jadi ditulis Indonesia.
- Beberapa contoh yang tidak bisa dipetakan skrip build tetap ditulis Indonesia, dan cocok dengan `id.json`: `catatan.md` di blok kode `Skill/` (tanpa garis miring, jadi tidak dipetakan), `01-Riset/` (contoh nama yang salah), `{folder, misalnya Proyek/, Relasi/Klien/}` di tabel Tim (baris itu berisi backtick, jadi teks di luar backtick tidak dipetakan). Contoh folder pribadi `kesehatan/` dan `jurnal/` di `.claudeignore` bukan folder bawaan, jadi tidak ada di `id.json`.
- Judul bagian `me.md` "How I want my agent to work" ditulis "Cara aku ingin agenku bekerja" (dirujuk di aturan utama 12).
- Daftar kata heboh di Cek Tulisan tetap memuat kata Inggrisnya, ditambah beberapa padanan Indonesia sebagai contoh.
