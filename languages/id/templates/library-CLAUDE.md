Pustaka berisi konten yang bisa dipakai ulang: prompt, templat, kerangka kerja, bahan referensi. Jaga supaya tetap ringkas.

## Aturan

- Kalau {Name} membagikan sesuatu yang bisa dipakai ulang, simpan di sini dengan nama file yang jelas.
- Buat subfolder hanya kalau sudah ada beberapa file sejenis (misalnya `prompts/`, `templates/`, `frameworks/`).
- Tautkan bahan dari proyek dan catatan harian dengan `[[wikilink]]`.
- Riset masuk ke `Memory/`, file proyek yang sedang berjalan masuk ke `Projects/`. Jangan menggandakannya di sini. Tautkan saja.
- Jangan simpan salinan file yang bisa diunduh atau karya orang lain. Catat saja di mana bisa mendapatkannya.
