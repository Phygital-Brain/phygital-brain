# Ordliste dansk (da)

## Tiltale

Uformelt "du", som i næsten alle danske forbruger-apps (MobilePay, DR, banker og webshops skriver "du"). "De" ville lyde gammeldags og stift. Det er det samme i hele sættet: i formularerne, beskederne og regelfilerne (også instruktionerne til agenten står i du-form). {Name} får aldrig et pronomen: hvor engelsk siger "they", gentager vi {Name} eller skriver sætningen om, så der aldrig bliver valgt et forkert køn. Roller som "Owner" er skrevet, så der ikke skal bruges et køn (i team-tabellen "Ejer", i teksten "Spørg ejeren ({Name})").

## Mapper (øverste niveau)

| Engelsk | Dansk |
|---|---|
| About | Profil |
| Daily | Dagbog |
| Projects | Projekter |
| Relationships | Kontakter |
| Memory | Hukommelse |
| Library | Bibliotek |
| Skills | Skills |

- **Profil** frem for "Om mig": ét ord, og mappen rummer mere end personen (mål, virksomhed, brand).
- **Dagbog**: én note pr. dag, og det er det ord, danskere bruger om sådan en.
- **Kontakter** frem for "Relationer": "relationer" lyder som parforhold eller som fagsprog.
- **Hukommelse**: det, hjernen husker over tid. "Arkiv" er allerede en undermappe.
- **Skills** bliver på engelsk, fordi agent-apps på dansk bruger ordet sådan. "Færdigheder" lyder fremmed her.

## Eksempler

Navnene (Ana, Marta, João, Lia) er de samme som på engelsk. Stedet i formularen er "København, Danmark" i stedet for "Lisbon, Portugal", og eksemplet på en hjemmeside er "https://ditwebsted.dk". I listen over private oplysninger nævner reglerne CPR-nummer og CVR-nummer, fordi det er dem, danskere kender.

## Pladsholdere i krøllede parenteser

Rigtige pladsholdere (`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` og så videre) bliver præcis, som de er. Parenteser med en instruktion eller en eksempeltekst, som agenten skriver ind i noten (for eksempel `{Én sætning: hvad den her fil indeholder.}`), er oversat, så teksten i noten bliver dansk.
