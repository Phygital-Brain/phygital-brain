كل مشروع مجلد يكبر كلما وصلت معلومات جديدة. `README.md` هو المدخل الوحيد.

## التوجيه

| المحتوى | المكان |
|---|---|
| نظرة عامة، الحالة، الموعد النهائي، الخطوات التالية | `Projects/{name}/README.md` |
| ملاحظات {Name} أثناء العمل | `Projects/{name}/notes/{topic}.md` |
| بحث | `Projects/{name}/research/{topic}.md` |
| وصف المشروع، المواصفات، المتطلبات | `Projects/{name}/briefs/{name}.md` |
| مسودات، نصوص، محتوى مكتوب | `Projects/{name}/drafts/{name}.md` |
| أفكار | `Projects/{name}/ideas/{name}.md` |
| آراء وملاحظات الآخرين | `Projects/{name}/feedback/{name}.md` |
| صور ووسائط | `Projects/{name}/assets/` |
| مواد قديمة من هذا المشروع | `Projects/{name}/archive/` |

أسماء المجلدات بأحرف صغيرة مع شرطات، بدون أرقام في بدايتها (`research/`، وليس `01-Research/`). يمكن للمشروع أن يضيف مجلده الخاص عندما لا يناسبه أي من هذه المجلدات.

## ترتيب ملف README

1. كتلة المعلومات (أدناه)، مع `description`.
2. `## ما هو`: سطر أو سطران، مع رابط إلى [[goals]].
3. `## الحالة والخطوة التالية`: أين وصل المشروع، والخطوة التالية.
4. `## كيف يعمل`: فقط إذا كان هناك شيء تلقائي يكتب هنا (مهمة مجدولة، سكربت).
5. `## أين توجد الأشياء`: فقط بعد وجود مجلدات فرعية. جدول صغير فيه رابط لكل مجلد.

## كتلة المعلومات (frontmatter)

```yaml
---
type: notes
date: 2026-10-13
status: active
project: Website-Redesign
tags: [website-redesign, notes]
---
```

- `type`: `project` (ملف README، وفيه أيضًا `created` و`updated` و`description`)، `notes`، `research`، `brief`، `draft`، `idea`، `feedback`، `plan`.
- `status`: `active`، `paused` أو `done`. حالة ملف README هي حالة المشروع.
- `project`: اسم مجلد المشروع.
- `tags`: المشروع، ثم النوع.

## القواعد

- المشروع الجديد هو مجرد `README.md`. أنشئ مجلدات فرعية فقط عندما يصل محتوى يحتاج إليها، واربطها من ملف README.
- ملف README هو الفهرس. لا تكرر فيه محتوى المجلدات الفرعية.
- لا `CLAUDE.md` داخل أي مشروع. قواعد مشروع واحد تذهب في "قواعد خاصة بكل مشروع" أدناه.
- ضع `project:` في كتلة المعلومات لكل ملاحظة مرتبطة.
- المشروع المنتهي ينتقل إلى `Memory/archive/{name}/` فقط عندما يقول {Name} ذلك.
- كل مشروع يجب أن يخدم هدفًا في [[goals]]. في الفحص الشامل، نبّه إلى الأهداف التي بلا مشروع والمشاريع التي بلا هدف.
