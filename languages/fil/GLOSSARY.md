# Glosaryo ng Filipino (fil)

Natural na Filipino na ginagamit ng mga tao sa apps ngayon, kasama ang mga salitang English na karaniwang sinasabi ng mga Pilipino (file, folder, project, note, link, chat, app, backup). Hindi malalim na Tagalog.

## Pakikipag-usap

Impormal, "ka/mo/ikaw", gaya ng GCash, Shopee, Grab at Facebook sa Filipino. Walang "po" at walang "kayo" bilang paggalang: utak mo ito, kaya parang kaibigan ang agent mo, hindi customer service. Pareho ito sa buong set: sa mga form, sa mga message at sa mga file ng patakaran. Ang mga utos para sa agent ay simpleng pautos ("Basahin ang...", "Magtanong muna", "Huwag baguhin") o may "mo" ("Basahin mo"). Ang tao mismo ay nagsasalita bilang "ako" ("ang utak ko", "ang idea ko").

Para kay {Name}, "siya", "niya" at "kanya" ang ginagamit. Walang kasarian ang mga ito sa Filipino, kaya hindi kailanman lalabas ang "he" o "she". Kung "they" ang English para sa grupo (kliyente, kumpanya), "sila" ang gamit. "May-ari" ang tawag sa owner sa team table, walang kasarian din.

## Mga folder (pinakaitaas)

| English | Filipino |
|---|---|
| About | Tungkol-sa-Akin |
| Daily | Araw-araw |
| Projects | Proyekto |
| Relationships | Kontak |
| Memory | Alaala |
| Library | Aklatan |
| Skills | Skills |

- **Tungkol-sa-Akin**: ganito ang tawag ng Facebook sa "About" sa Filipino ("Tungkol"), at malinaw na tungkol sa iyo ang laman (layunin, negosyo, brand).
- **Araw-araw**: isang note bawat araw. Mas natural kaysa "Talaarawan", na parang lumang diary.
- **Kontak** sa halip na "Mga Ugnayan": parang love life ang "ugnayan". "Kontak" ang tawag ng mga tao sa listahan ng mga tao at kumpanya.
- **Skills** ay nananatili, dahil "skills" ang sinasabi ng mga Pilipino at ng mga AI app. Masyadong pormal ang "Kasanayan".
- Iisahan ang mga pangalan (Proyekto, hindi Mga-Proyekto), gaya ng karaniwang pangalan ng folder.

- **me = profile**, hindi "ako": para natural basahin ang `[[profile]]` kahit sino ang nagsasalita.
- **customers = mamimili**, hindi "kliyente": para hindi magkalito ang `mamimili.md` sa Tungkol sa Akin at ang folder na `Kliyente` sa Kontak.
- **finances = pera**: ganito ito sabihin ng mga tao. Masyadong pormal ang "pananalapi".
- **daily = pang-araw-araw**: ang file ng Taga-ayos ng Utak. Iba ito sa folder na `Araw-araw`, para hindi magkalito.
- **queue = nakabinbin**: ang mga bagay na naghihintay pa. Sa teksto, "listahan ng nakabinbin" ang tawag sa file.
- **_Leads = _Posibleng-kliyente**: hindi lahat nakakaintindi ng "leads".
- **research, notes, draft, brief, prompt, template, framework, feedback, media, tools, brand, archive**: mga salitang English na ginagamit talaga ng mga freelancer at creator sa Pilipinas. Mas kakaiba pakinggan ang malalim na Tagalog.
- Mga pribadong folder sa `.claudeignore`: `kalusugan/` at `personal-na-journal/` (nakakomento ang mga ito at hindi path ng utak, kaya isinalin).

## Mga trigger na sinasabi ng tao

Filipino muna, saka ang English, para gumana pareho: "i-check up ang utak ko", "ayusin ang utak ko", "buod sa umaga", "i-set up ang buod sa umaga ko", "ihanda mo ako para kay...", "kontrahin mo ang idea ko", "anong pattern ang nakikita mo?", "hanapin ang mga nagkakasalungat", "ipasok ang mga luma kong note", "i-undo ang huling binago", "i-set up ang team ko", "ihinto muna ang taga-ayos ng utak", "ituloy ulit ang taga-ayos ng utak".

## Mga placeholder sa curly braces

Ang mga totoong placeholder (`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` at iba pa) ay nananatili nang eksakto. Ang mga braces na may utos sa pagpuno o halimbawang teksto na isusulat ng agent sa note (halimbawa `{Isang pangungusap: ano ang laman ng file na ito.}`) ay isinalin, para Filipino ang lalabas sa note.
