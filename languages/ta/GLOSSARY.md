# தமிழ் சொற்களஞ்சியம் (ta)

## பேசும் விதம்

மரியாதையான "நீங்கள்", தமிழ்நாட்டிலும் இலங்கையிலும் பிரபலமான ஆப்கள் (Google, WhatsApp, PhonePe, Swiggy) பேசுவது போல. செட் முழுவதும் ஒரே மாதிரி: படிவங்கள், மெசேஜ்கள், விதி ஃபைல்கள் (ஏஜென்டுக்கான வழிமுறைகளும் "-ங்கள்" வடிவத்தில்: படியுங்கள், எழுதுங்கள்).

- **பட்டன்கள்:** ஆப்களில் வழக்கமான "-வும்" வடிவம்: தொடரவும், தவிர்க்கவும், ஃபைலைத் தேர்ந்தெடுக்கவும்.
- **ஒருவர் தன் ஏஜென்டிடம் சொல்வது:** சாதாரண ஏவல் வடிவம் (செய், சொல், காட்டு), ஒரு உதவியாளரிடம் மக்கள் உண்மையில் பேசுவது போல: "என் பிரெயினை செக்-அப் செய்". தூண்டும் சொற்கள் இந்த வடிவத்தில், அதைத் தொடர்ந்து ஆங்கிலச் சொற்றொடர்.
- **{Name}-க்கு பாலினம் இல்லை:** வினைகள் மரியாதைப் பன்மை "-ஆர்" வடிவத்தில் (சொல்வார், கேட்பார்), இது எந்தப் பாலினத்துக்கும் பொருந்தும். "அவன்", "அவள்" ஒருபோதும் இல்லை. முடிந்த இடங்களில் {Name} என்றே மீண்டும் எழுதப்பட்டுள்ளது, "தன்" போன்ற பாலினம் இல்லாத சொற்களும் பயன்படுகின்றன.
- **எளிய தமிழ்:** இலக்கியத் தமிழ் அல்ல, மக்கள் உண்மையில் பயன்படுத்தும் ஆங்கிலச் சொற்களுடன்: ஃபைல், ஃபோல்டர், லிங்க், பேக்கப், சாட், ஆப், செட்டப், டேக், மீட்டிங், கிளையன்ட். ஆனால் எல்லோருக்கும் தெரிந்த தமிழ்ச் சொல் இருந்தால் அதுவே: குறிப்பு, திட்டம், மின்னஞ்சல், அறிக்கை, கருவி.
- எண்கள் இலக்கங்களாகவே. வாக்கியம் முற்றுப்புள்ளியுடன் முடியும்.

## ஃபோல்டர்கள் (மேல் நிலை)

தமிழில் பெரிய எழுத்து இல்லை, அதனால் மேல் ஃபோல்டர்கள் வெறும் சொல்லாகவே இருக்கும். பல சொற்கள் உள்ள பெயர்களில் சொற்களுக்கு இடையே hyphen.

| ஆங்கிலம் | தமிழ் |
|---|---|
| About | அறிமுகம் |
| Daily | தினசரி |
| Projects | திட்டங்கள் |
| Relationships | தொடர்புகள் |
| Memory | நினைவகம் |
| Library | நூலகம் |
| Skills | திறன்கள் |

- **அறிமுகம்**, "என்னைப் பற்றி" அல்ல: ஒரே சொல், ஃபோல்டரில் அந்த நபர் மட்டுமல்ல, இலக்குகள், தொழில், பிராண்ட் எல்லாம் இருக்கின்றன.
- **தொடர்புகள்**, "உறவுகள்" அல்ல: "உறவுகள்" குடும்பம் போலத் தோன்றும். இந்த ஃபோல்டரில் கிளையன்ட்கள், சக படைப்பாளிகள், குழு, கூட்டாளிகள் இருக்கிறார்கள்.
- **நினைவகம்**, "நினைவுகள்" அல்ல: "நினைவுகள்" என்றால் இனிய பழைய நினைவுகள். "நினைவகம்" என்பது சேர்த்து வைக்கும் இடம்.
- **திறன்கள்**: ஏஜென்ட் பயன்படுத்தும் skills, எளிய சொல்.

- **Clients = கிளையன்ட்கள், customers = வாடிக்கையாளர்கள்:** இரண்டும் "வாடிக்கையாளர்கள்" ஆனால், அறிமுகத்தில் உள்ள `வாடிக்கையாளர்கள்.md`-உம் தொடர்புகளில் உள்ள ஃபோல்டரும் குழம்பும். வேலை செய்து கொடுக்கும் நபர்களுக்கு "கிளையன்ட்" என்பதே தமிழ்நாட்டில் வழக்கம்.
- **Collaborators = சக-படைப்பாளிகள்:** இந்த ஃபோல்டர் படைப்புக் கூட்டாளிகளுக்கானது, பணம் இல்லாத பரிமாற்றம். "கூட்டாளிகள்" Partners-க்கு (பத்திரிகைகள், நிகழ்ச்சி இடங்கள், பிளாட்ஃபார்ம்கள்).
- **Brain Keeper-இன் `daily.md` = தினசரி-சுத்தம்**, `Daily` ஃபோல்டருடன் (தினசரி) குழம்பாமல் இருக்க.
- **tasks = செய்ய-வேண்டியவை:** "வேலைகள்" என்றால் job, work என்றும் பொருள் வரும்.
- **queue = நிலுவை:** "வரிசை" தொழில்நுட்பம் போலத் தோன்றும். உரையில் இந்த ஃபைல் "நிலுவைப் பட்டியல்".
- **_Leads = _வாய்ப்புகள்:** "லீட்" எல்லோருக்கும் தெரியாது. உரையில் lead = "வாய்ப்பு".
- **assets = மீடியா:** இந்த ஃபோல்டரில் படங்களும் மீடியாவும் இருக்கும்.
- **cv = சுயவிவரம்:** வேலைக்கான CV-க்கு தமிழில் வழக்கமான சொல்.

உண்மையான placeholders (`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` போன்றவை) அப்படியே இருக்கும். ஏஜென்ட் குறிப்பில் எழுதும் நிரப்பும் வழிமுறை அல்லது உதாரண உரை உள்ள அடைப்புக்குறிகள் (உதாரணமாக `{ஒரு வாக்கியம்: இந்த ஃபைலில் என்ன இருக்கிறது.}`) மொழிபெயர்க்கப்பட்டுள்ளன, அப்போதுதான் குறிப்பில் உள்ள உரை தமிழில் இருக்கும்.
