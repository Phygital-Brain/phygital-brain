# Glossar Deutsch (de)

## Anrede

Informell, "du", wie in den meisten deutschen Consumer-Apps. Im ganzen Set gleich: in den Formularen, den Meldungen und den Regeldateien (auch die Anweisungen an den Agenten sind in der Du-Form). Für {Name} gibt es kein Pronomen: Wo das Englische "they" sagt, steht wieder {Name}, damit nichts falsch gegendert wird. Rollen wie "Owner" sind so formuliert, dass kein Geschlecht nötig ist (in der Team-Tabelle "Verantwortlich", im Text "Frag erst {Name}").

## Ordner (oberste Ebene)

| Englisch | Deutsch |
|---|---|
| About | Profil |
| Daily | Tagebuch |
| Projects | Projekte |
| Relationships | Kontakte |
| Memory | Gedächtnis |
| Library | Bibliothek |

- **Profil** statt "Über mich": ein Wort, und der Ordner enthält mehr als nur die Person (Ziele, Unternehmen, Marke).
- **Kontakte** statt "Beziehungen": "Beziehungen" klingt nach Liebesleben.
- **Skills** bleibt, weil Agent-Apps auf Deutsch das Wort so verwenden. "Fähigkeiten" klingt hier fremd.

## Beispiele

Die Namen (Ana, Marta, João, Lia) bleiben wie im Englischen. Der Ort im Formular ist "Berlin, Deutschland" statt "Lisbon, Portugal", die Beispiel-Website "https://deineseite.de".

## Platzhalter in geschweiften Klammern

Echte Platzhalter (`{Name}`, `{Language}`, `{person or company}`, `{weekday in English}` und so weiter) bleiben genau so. Klammern, die eine Ausfüll-Anweisung oder einen Beispieltext enthalten, den der Agent in die Notiz schreibt (zum Beispiel `{Ein Satz: was in dieser Datei steht.}`), sind übersetzt, damit der Text in der Notiz deutsch ist.
