ప్రతి ప్రాజెక్ట్ ఒక ఫోల్డర్, సమాచారం వచ్చే కొద్దీ అది పెరుగుతుంది. `README.md` ఒక్కటే మొదటి పేజీ, అక్కడి నుంచే మిగతావన్నీ.

## ఏది ఎక్కడికి

| కంటెంట్ | ఎక్కడికి |
|---|---|
| మొత్తం చిత్రం, స్టేటస్, డెడ్‌లైన్, తర్వాతి అడుగులు | `Projects/{name}/README.md` |
| {Name} పని నోట్స్ | `Projects/{name}/notes/{topic}.md` |
| పరిశోధన | `Projects/{name}/research/{topic}.md` |
| బ్రీఫ్, స్పెక్, అవసరాలు | `Projects/{name}/briefs/{name}.md` |
| డ్రాఫ్ట్‌లు, స్క్రిప్ట్‌లు, రాసిన కంటెంట్ | `Projects/{name}/drafts/{name}.md` |
| ఐడియాలు | `Projects/{name}/ideas/{name}.md` |
| అభిప్రాయాలు | `Projects/{name}/feedback/{name}.md` |
| బొమ్మలు, మీడియా | `Projects/{name}/assets/` |
| ఈ ప్రాజెక్ట్ పాత మెటీరియల్ | `Projects/{name}/archive/` |

ఫోల్డర్ పేర్లు చిన్న అక్షరాల్లో, హైఫన్లతో, ముందు నంబర్లు లేకుండా (`research/`, `01-Research/` కాదు). వీటిలో ఏదీ సరిపోకపోతే ఒక ప్రాజెక్ట్ తన సొంత ఫోల్డర్ జోడించుకోవచ్చు.

## README ఆకారం

1. ఇన్ఫో బ్లాక్ (కింద), ఒక `description`తో.
2. `## ఇది ఏంటి`: ఒకటి రెండు లైన్లు, [[goals]]కి లింక్‌తో.
3. `## ఇప్పటి స్థితి, తర్వాతి అడుగు`: ఎక్కడిదాకా వచ్చింది, తర్వాతి అడుగు.
4. `## ఇది ఎలా నడుస్తుంది`: ఇక్కడ ఏదైనా ఆటోమేటిక్‌గా రాస్తేనే (ఒక షెడ్యూల్ టాస్క్, ఒక స్క్రిప్ట్).
5. `## ఏది ఎక్కడ ఉంది`: సబ్‌ఫోల్డర్లు వచ్చాకే. ఒక్కోదానికీ లింక్ ఇచ్చే చిన్న టేబుల్.

## ఇన్ఫో బ్లాక్ (frontmatter)

```yaml
---
type: notes
date: 2026-10-13
status: active
project: Website-Redesign
tags: [website-redesign, notes]
---
```

- `type`: `project` (README, దానికి `created`, `updated`, `description` కూడా ఉంటాయి), `notes`, `research`, `brief`, `draft`, `idea`, `feedback`, `plan`.
- `status`: `active`, `paused` లేదా `done`. README స్టేటసే ప్రాజెక్ట్ స్టేటస్.
- `project`: ప్రాజెక్ట్ ఫోల్డర్ పేరు.
- `tags`: ప్రాజెక్ట్, తర్వాత రకం.

## నియమాలు

- కొత్త ప్రాజెక్ట్ అంటే ఒక `README.md` మాత్రమే. అవసరమైన కంటెంట్ వచ్చినప్పుడే సబ్‌ఫోల్డర్లు తయారు చేయండి, README నుంచి వాటికి లింక్ ఇవ్వండి.
- README విషయ సూచిక. సబ్‌ఫోల్డర్లలో ఉన్నదాన్ని అందులో మళ్ళీ రాయకండి.
- ప్రాజెక్ట్ లోపల `CLAUDE.md` వద్దు. ఒక్క ప్రాజెక్ట్ నియమాలు కింద "ప్రతి ప్రాజెక్ట్ సొంత నియమాలు"లోకి వెళ్తాయి.
- సంబంధం ఉన్న ప్రతి నోట్ ఇన్ఫో బ్లాక్‌లో `project:` పెట్టండి.
- పూర్తయిన ప్రాజెక్ట్ {Name} చెప్పినప్పుడు మాత్రమే `Memory/archive/{name}/`కి వెళ్తుంది.
- ప్రతి ప్రాజెక్ట్ [[goals]]లోని ఏదో ఒక లక్ష్యానికి ఉపయోగపడాలి. చెకప్‌లో, ప్రాజెక్ట్ లేని లక్ష్యాలను, లక్ష్యం లేని ప్రాజెక్టులను చూపించండి.
