# తెలుగు పదకోశం (te)

## మాట తీరు

- **యాప్, ఏజెంట్ వ్యక్తితో: "మీరు"**, మర్యాదగా చెప్పే రూపంతో (చేయండి, చూడండి, ఎంచుకోండి). Google, WhatsApp, PhonePe లాంటి పెద్ద యాప్స్ తెలుగులో ఇలాగే మాట్లాడతాయి. ఫారాలు, మెసేజ్‌లు, నియమాల ఫైల్స్ (ఏజెంట్‌కి ఇచ్చే సూచనలు కూడా) అన్నిటిలోనూ ఇదే.
- **వ్యక్తి తన ఏజెంట్‌తో: "నువ్వు" రూపం** (చేయి, ఇవ్వు, చెప్పు). మనుషులు అసిస్టెంట్‌తో నిజంగా ఇలాగే మాట్లాడతారు: "నా బ్రెయిన్ చెకప్ చేయి". ట్రిగ్గర్ మాటలు ఈ రూపంలో, తర్వాత ఇంగ్లీష్ మాట.
- **{Name}కి లింగం లేదు.** "ఆయన", "ఆమె" వాడం. {Name}ని మళ్ళీ రాస్తాం, క్రియలు గౌరవ బహువచనంలో (అడిగారు, చెప్పారు, అంటారు), ఇవి ఎవరికైనా సరిపోతాయి. "Owner"ని "యజమాని" అన్నాం.
- ఏజెంట్, బ్రెయిన్ కీపర్ నపుంసక లింగం: "చేస్తుంది", "చూసుకుంటుంది".
- మామూలుగా మాట్లాడే తెలుగు, జనం నిజంగా వాడే ఇంగ్లీష్ పదాలతో: ఫైల్, ఫోల్డర్, నోట్స్, లింక్, ప్రాజెక్ట్, క్లయింట్, టూల్స్, యాప్, బ్యాకప్, రిపోర్ట్, చాట్, ఈమెయిల్, సెటప్, డిలీట్. గ్రాంథిక పదాలు వద్దు (ఉదాహరణకు "తొలగించు" బదులు "డిలీట్ చేయి", "ఆదేశం" సరే కానీ "ఆజ్ఞ" వద్దు).
- {Name}, {name} లాంటి ప్లేస్‌హోల్డర్ల తర్వాత విభక్తి ప్రత్యయం నేరుగా అతుకుతుంది: {Name}కి, {Name}తో, {Language}లో.
- అంకెలు అంకెలుగానే. వాక్యం చివర ఫుల్‌స్టాప్.

## ఫోల్డర్లు (మొదటి స్థాయి)

| ఇంగ్లీష్ | తెలుగు |
|---|---|
| About | పరిచయం |
| Daily | రోజువారీ |
| Projects | ప్రాజెక్టులు |
| Relationships | కాంటాక్టులు |
| Memory | జ్ఞాపకం |
| Library | లైబ్రరీ |
| Skills | స్కిల్స్ |

- తెలుగులో పెద్ద అక్షరాలు లేవు, కాబట్టి మొదటి స్థాయి ఫోల్డర్లు మామూలు పదాలే. పేరులో రెండు పదాలు ఉంటే హైఫన్‌తో కలుపుతాం.
- **పరిచయం**, "నా గురించి" కాదు: ఒక్క పదం, ఈ ఫోల్డర్‌లో వ్యక్తి గురించే కాక లక్ష్యాలు, వ్యాపారం, బ్రాండ్ కూడా ఉంటాయి.
- **కాంటాక్టులు**, "సంబంధాలు" కాదు: తెలుగులో "సంబంధం" అంటే పెళ్ళి సంబంధం అని కూడా అర్థం. "పరిచయాలు" కూడా వద్దు, "పరిచయం" ఫోల్డర్‌తో కలిసిపోతుంది. ఫోన్లలో "కాంటాక్టులు" అందరికీ తెలుసు.
- **జ్ఞాపకం**, "జ్ఞాపకాలు" కాదు: బహువచనం ఫొటోల జ్ఞాపకాల్లా, మధుర స్మృతుల్లా వినిపిస్తుంది. ఇక్కడ ఉండేవి నిర్ణయాలు, పరిశోధన, ఆర్కైవ్.
- **లైబ్రరీ**, "గ్రంథాలయం" కాదు: రోజూ మాట్లాడే మాట.
- **స్కిల్స్**: ఏజెంట్ యాప్స్ ఈ పదాన్నే వాడతాయి. "నైపుణ్యాలు" రెజ్యూమేలోని నైపుణ్యాల్లా వినిపిస్తుంది.
