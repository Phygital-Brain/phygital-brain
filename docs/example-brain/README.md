# Example brain

A few notes from a made-up brain, so you can see what the files look like before you build your own. They belong to Ana, the illustrator from [Use cases](../use-cases.md), one week after her setup.

A real brain has more: a rule file (`CLAUDE.md`) in every folder, and more notes. The rule files are the templates in [`skills/brain-setup/templates/`](../../skills/brain-setup/templates/), filled in with the person's name and choices.

```
Ana's brain (example)
├── About/
│   ├── me.md                     who she is and how she wants her agent to work
│   └── services.md               what she offers, and her prices
├── Daily/
│   ├── 2026-10-20.md             one day's note
│   └── tasks.md                  open tasks not tied to a project
├── Projects/
│   └── Picture-Book/README.md    a project's front page
├── Relationships/
│   └── Clients/
│       ├── Penguin Kids.md       a client note
│       └── _Leads.md             people who might become clients
├── Memory/
│   └── decisions/
│       └── 2026-10-23-raise-cover-price.md
└── Skills/
    └── brain-keeper/
        ├── queue.md              what needs Ana
        └── reports/2026-10-24.md one Brain Keeper report
```

| File | Shows |
|---|---|
| [About/me.md](About/me.md) | Current truth at the top, dated evidence below |
| [About/services.md](About/services.md) | Offers and prices from her price list |
| [Daily/2026-10-20.md](Daily/2026-10-20.md) | Short entries with links, and the day tags |
| [Daily/tasks.md](Daily/tasks.md) | Open and done tasks with dates |
| [Projects/Picture-Book/README.md](Projects/Picture-Book/README.md) | A project front page |
| [Relationships/Clients/Penguin Kids.md](Relationships/Clients/Penguin%20Kids.md) | A client with a contact person inside the note |
| [Relationships/Clients/_Leads.md](Relationships/Clients/_Leads.md) | New leads and ones to keep warm |
| [Memory/decisions/2026-10-23-raise-cover-price.md](Memory/decisions/2026-10-23-raise-cover-price.md) | A decision with the reason and the risk |
| [Skills/brain-keeper/queue.md](Skills/brain-keeper/queue.md) | What only Ana can decide |
| [Skills/brain-keeper/reports/2026-10-24.md](Skills/brain-keeper/reports/2026-10-24.md) | What the daily tidy did |

Everything here is made up: the people, companies, prices and contact details.
